# ギジログ

ビデオ会議を録音しながら、議事録をその場で書き上げていく macOS アプリです。
会議中は小さな画面を会議の横に置き、決まったこと・残っている論点・担当を確かめながら進行できます。

## できること

- **録音**：Zoom・Teams・Google Meet などに参加したまま、Mac から出る音とマイクの声を録音します。会議アプリの設定は変えません。
- **リアルタイムの議事録**：約12秒ごとに OpenAI で文字起こしし、30秒ごとに議事録を書き足します。
- **進行しやすい小画面**：決定事項・未決事項・アクションアイテムを並べ、直近の更新で変わった項目に色を付けます。担当や期限が決まっていないアクションは目立たせるので、その場で確認できます。
- **根拠のある議事録**：議事録の各項目には、もとになった発言の時刻が付きます。発言に根拠のない項目や、発言にない担当者・期限は載せません。
- **録音ファイルからも作成**：ボイスメモや Zoom の録画など、あとから音声・動画ファイルを読み込んで議事録にできます。
- **音声と議事録をまとめて保存**：会議ごとのフォルダに `議事録.md` と `録音.m4a` を残します。

## 必要なもの

- macOS 15 以降
- OpenAI の API キー（利用料は各自の負担です）
- ビルドする場合：Swift 6 以降（Xcode または Command Line Tools）と [SwiftLint](https://github.com/realm/SwiftLint)

## はじめかた

```sh
brew install swiftlint
git clone https://github.com/nutcase/gijilog.git
cd gijilog
./scripts/build.sh
open dist/ギジログ.app
```

1. 設定（⌘,）で OpenAI の API キーを保存します。
2. 「録音を開始」を押します。初回は macOS が「画面とシステムオーディオの録音」の許可を求めるので、システム設定で「ギジログ」をオンにしてアプリを開き直してください。マイクの許可も求められます。
3. もう一度「録音を開始」を押すと、録音と議事録づくりが始まります。

> [!NOTE]
> 開発用の署名（ad-hoc）でビルドすると、ビルドし直すたびに録音の許可が外れます。外れたときは次のコマンドで古い許可を消し、2. からやり直してください。固定の署名で避ける方法は「[ビルドし直しても許可を保つ](#ビルドし直しても許可を保つ)」にあります。
>
> ```sh
> tccutil reset ScreenCapture io.github.nutcase.gijilog
> ```

## 使い方

### 会議中は小画面で

録音を始めると小画面に切り替わり、ほかのウインドウより手前に表示されます。

- 上部：経過時間、Mac 音声とマイクの音量の波形、停止ボタン。マイクの波形が平らなままなら、声が入っていません。
- 本文：決定事項 → 未決事項 → アクションアイテム → 要約の順に並びます。
- 下端：最新の発言。
- ピンで手前への固定を外せます。矢印のボタンで大きい画面に戻ります。画面を切り替えても録音は続きます。

### 会議のあとは大きい画面で

議事録を中央に、文字起こしを右に並べて表示します。録音中の文字起こしは最新の発言まで自動でスクロールし、読み返している間は止まります。

ツールバーからできること：

| ボタン | 内容 |
| --- | --- |
| 書き出し | 議事録と文字起こしを Markdown で好きな場所に保存 |
| この会議 | 未処理を再開、全文を再処理、Finder で表示、ゴミ箱に移動 |
| 小画面にする | 小画面に切り替え |
| 文字起こし | 右側の文字起こしの表示を切り替え |

文字起こしに失敗すると、大きい画面と小画面の両方に原因と「再試行」ボタンが出ます。録音中でも、失敗した部分だけをやり直せます。

### 録音ファイルから作る

「ファイルから作成」で音声・動画ファイルを選ぶか、ファイルをウインドウにドロップします。複数のファイルをまとめて選ぶこともできます。

- 音声を約30秒ずつに分けて文字起こしし、終わったら議事録を作ります。
- タイトルはファイル名、日時はファイルの作成日時になります。
- 会議フォルダに `議事録.md` と `録音.m4a` を作ります。元のファイルはそのまま残ります。

### 保存されるもの

保存先は、既定では書類フォルダの `ギジログ` です。設定で変更でき、変更するとこれまでの会議も移動します。

```text
~/Documents/ギジログ/
└── 2026-10-03 17.26 週次定例/
    ├── 議事録.md        議事録と文字起こし（更新のたびに書き直します）
    ├── 録音.m4a         Mac 音声とマイクを重ねた聞き返し用の音声（録音の停止後に作成）
    ├── system.caf       ここから下はアプリが使うデータ
    ├── microphone.caf
    ├── chunks/
    ├── recording.json
    └── meeting.json
```

`議事録.md` はアプリが書き直すので、手を加えるときは別名で保存してください。

### 設定

| 項目 | 内容 |
| --- | --- |
| API キー | OpenAI の API キー。Mac の Keychain に保存します |
| 議事録のモデル | 議事録を作るモデル（初期値 `gpt-6-sol`）。文字起こしは `gpt-4o-transcribe` です |
| マイク | 録音するマイク。会議の音はイヤホンで聞き、声は Mac 本体のマイクで録るのがおすすめです |
| 保存先 | 会議フォルダを置く場所 |

## プライバシーと録音の同意

- **OpenAI に送るもの**：約12秒ごとの音声（無音の部分は送りません）、文字起こしの文章、それまでの議事録。議事録の生成は `store: false` で依頼します。
- **Mac に残るもの**：録音、文字起こし、議事録。API キーは Keychain にあり、会議のファイルには書き込みません。
- **同意**：会議を録音・文字起こしするときは、参加者に伝えて同意を得てください。録音に関する法令や所属先の規程にも従ってください。
- **確認**：議事録は AI による要約です。大事な内容は文字起こしの原文で確かめてください。

書類フォルダを iCloud Drive と同期している場合は、録音もアップロードされます。

## 制限

- 話者は区別しません。「Mac 音声」「マイク」は音が入ってきた経路です。
- スピーカーで会議の音を流すとマイクにも入り、二重に録音されます。イヤホンを使ってください。
- 30秒は更新の間隔の目安です。通信や API が遅いと遅れます。
- 長い会議では、それまでの議事録も毎回送るため、モデルの入力上限に近づくことがあります。
- 配布用の署名と公証には対応していません。ソースからビルドして使ってください。

## 開発

```sh
./scripts/check.sh   # 整形チェック → SwiftLint → 回帰テスト → リリースビルド
./scripts/format.sh  # Swift コードを整形
./scripts/test.sh    # 回帰テストだけ
./scripts/build.sh   # チェックに通ったら dist/ギジログ.app を作る
```

- 整形は [swift-format](https://github.com/swiftlang/swift-format)（`.swift-format`）、静的チェックは SwiftLint（`.swiftlint.yml`）で、警告もエラーとして扱います。
- 回帰テスト（36件）は、録音の分割と時刻合わせ、議事録の差分更新と根拠の検証、再試行と再起動からの復旧、保存先の移動と以前の版からの引き継ぎ、録音ファイルの合成と読み込みなどを確かめます。音声認識と API は模擬応答で、模擬していない通信はテスト中すべて失敗させます。
- GitHub Actions で、push と Pull Request ごとに SwiftLint・回帰テスト・リリースビルドを実行します。
- Command Line Tools だけの環境では、SwiftUI の `@State` がコンパイルできません。画面の状態は `ObservableObject` に持たせています。

| ファイル | 役割 |
| --- | --- |
| `Recorder.swift` | ScreenCaptureKit で Mac 音声とマイクを録音し、約12秒ごとに区切る |
| `Pipeline.swift` | 文字起こしの並行処理（最大2件）、再試行、議事録の更新要求のまとめ |
| `MinutesEngine.swift` | 議事録の差分更新、根拠の検証、Markdown の作成 |
| `Processing.swift` | OpenAI への送信、無音の除外、録音ファイルの合成と読み込み |
| `Store.swift` | 録音の開始・停止、保存、再起動後の復旧、保存先の移動 |
| `Views.swift` | 大きい画面・小画面・設定 |

### ビルドし直しても許可を保つ

キーチェーンアクセスの「証明書アシスタント」→「証明書を作成」で、種類「自己署名ルート」、証明書のタイプ「コード署名」の証明書を作り、その名前を指定してビルドします。

```sh
GIJILOG_SIGN_IDENTITY="ギジログ開発" ./scripts/build.sh
```
